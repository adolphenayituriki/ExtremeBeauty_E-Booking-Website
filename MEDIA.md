# Extreme Beauty Lashes & Brows

## Image & Media Assets

Place your media files in the following folders:

### Frontend (frontend/src/assets/)
- `frontend/src/assets/logo/` — Logo files (SVG, PNG)
- `frontend/src/assets/images/` — Source images used in components
- `frontend/src/assets/videos/` — Source videos used in components

### Frontend Public (frontend/public/)
- `frontend/public/images/` — Public images (hero, backgrounds, service images)
- `frontend/public/videos/` — Public videos
- `frontend/public/logo/` — Public logo files

### Backend Uploads (backend/uploads/)
- `backend/uploads/images/` — Uploaded images
- `backend/uploads/videos/` — Uploaded videos
- `backend/uploads/logo/` — Uploaded logos

## Image Specifications

- **Hero images**: 1920x1080px recommended
- **Category cards**: 800x800px recommended
- **Service cards**: 800x600px recommended
- **Logo**: SVG or PNG with transparent background, max 500px width
- **Format**: JPG for photos, PNG for graphics with transparency, SVG for logos
